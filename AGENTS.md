# Python Classic Architecture

## Цель
Цель - создать скиллы для ИИ, по которым агенты смогут создавать приложения по чистой архитектуре.

## Описание

### Skills
Скиллы находятся в .opencode\skills: архитектурные навыки `python-classic-*`
и ролевые навыки агентного пайплайна `agent-*` (аналитик, архитектор,
разработчик, ревьюер). Пайплайн описан в docs\pipeline.md, шаблоны
артефактов - в docs\templates.

### Demo
В docs\demo-spec.md находится спецификация для демо-проекта.

В src размещен код демо, в tests - тесты для демо.
