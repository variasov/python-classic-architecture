# Python SQL DB adapter in "Classic" Architecture 

## Описание

В этом навыке описывается адаптер к SQL DB для приложений на Python,
соответствующий шаблону "Классической" архитектуры.

## Когда использовать
- Во время разработки новых фич в Python-приложении, требующих доступа к SQL DB.

## Instructions
- Для работы с SQL-запросами используется classic-db-tools + драйвер для БД.
- Запросы предпочтительно размещать в файлах в директории sql в адаптере.
- Статические запросы предпочтительнее, лучше обходиться ими.
- Динамические запросы предпочтительны, когда у запроса меняется форма в зависимости от входных параметров,
  например, добавляются условия в WHERE, добавляются JOIN, меняется ORDER BY и т.д.
