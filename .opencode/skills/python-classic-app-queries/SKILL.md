# Python app Query in "Classic" Architecture 

## Описание

В этом навыке описывается раттерн для объектов-запросов в приложениях на Python,
соответствующих шаблону "Классической" архитектуры.

## Когда использовать
- Во время разработки новых фич в Python-приложении, связанных с передачей данных вызывающей системе или пользователю.

## Instructions
- Объект-запрос (Query) предназначен для выдачи данных из системы наружу. К таким классам не должно быть обращения из уровня приложения, только из адаптеров.
- Объект должен иметь только один метод - .run. Метод должен быть идемпотентным.
- Параметры принимаются в виде датаклассов или простых типов данных. Параметры описываются в том же файле, что и объект-запрос.
- Результат запроса возвращается в виде датаклассов или простых типов данных. Возвращаемые DTO описываются рядом в том же файле, и между разными классами-запросами НЕ переиспользуются.
- Объект-запрос отвечает за проверку прав при необходимости.
- Внутри объект запрос должен обратиться к хранилищу, передав нужные параметры, сконвертировать в результирующий вид и вернуть данные наружу.
- Для доступа к SQL DB при необходимости используется classic-db-tools+драйвер для БД.
