# Python app Commands in "Classic" Architecture 

## Описание

В этом навыке описывается раттерн для объектов-комманд в приложениях на Python,
соответствующих шаблону "Классической" архитектуры.

## Когда использовать
- Во время разработки новых фич в Python-приложении, связанных с изменением состояния приложения.

## Instructions
- Объект-команда (Query) предназначен для изменения состояния системы (бизнес-объектов) по заложенным бизнес-правилам. К таким классам не должно быть обращения из уровня приложения, только из адаптеров.
- Объект должен иметь только один метод - .run.
- Параметры принимаются в виде датаклассов или простых типов данных. Параметры описываются в том же файле, что и объект-запрос.
- Результат запроса возвращается в виде датаклассов или простых типов данных. Возвращаемые DTO описываются рядом в том же файле, и между разными классами-запросами НЕ переиспользуются.
- Объект-команда отвечает за проверку прав при необходимости.
- Внутри объект запрос должен обратиться к хранилищу, передав нужные параметры, сконвертировать в результирующий вид и вернуть данные наружу.
- Для доступа к SQL DB при необходимости используется classic-db-tools+драйвер для БД.
- Рядом с командой в том же файле могут быть описаны дополнительные датаклассы, необходимые для работы UseCase.
