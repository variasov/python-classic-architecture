# 10. Напоминания о просрочке

Ежедневная задача планировщика создаёт уведомления `loan_overdue` по просроченным выдачам.

## Спецификация
- Команда `RemindOverdueLoans`; «Уведомления»; «Процессы» - точка входа `overdue_scheduler`.

## Скиллы
`python-classic-app`, `python-classic-composite` + `classic-scheduler`.

## Сделать
- App: `commands/loans/remind_overdue_loans.py` (без прав, фоновый).
- Композит: инстанс команды с транзакцией на `run`; точка входа `interfaces/overdue_scheduler`
  (`__main__.py`, cron `0 9 * * *`); регистрация задачи вынесена в функцию сборки, чтобы её можно было
  проверить без запуска планировщика.

## Критерии приёмки
- Unit app: создаёт уведомления только по просроченным выдачам и только если их ещё нет;
  возвращает число новых; замороженное время.
- E2E: просроченная выдача на тестовой БД → вызов задачи планировщика создаёт уведомление,
  повторный вызов - не создаёт; задача зарегистрирована с расписанием `0 9 * * *`.
