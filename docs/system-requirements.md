# Demo-приложение

## Overview

В этом документе описываются требования к системе.

## Назначение

Система предназначена для демонстрации архитектурyых паттернов.

## Функциональные требования

Система должна иметь функционал для хранения и поиска информации о котах.
Для каждого кота описывается кличка, возраст, настроение (в свободной форме), история перемещения с координатами.
Поиск должен осуществляться по уникальному ID, диапазону возрастов.
Аутентификация и авторизация на этом этапе не нужна.

## Технические требовани
- В качестве БД должна использоваться SQLite.
- Система должна иметь HTTP REST API.
